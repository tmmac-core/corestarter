# Reporting security issues / Sicherheitslücken melden

Please do **not** open a public issue for security problems. Report them privately via the **Security** tab →
**Report a vulnerability** in this repository.

Bitte melde Sicherheitslücken **nicht** als öffentliches Issue, sondern vertraulich über GitHub:
Reiter **Security** → **Report a vulnerability** in diesem Repository.

- We reply within 7 days. / Wir antworten innerhalb von 7 Tagen.
- Only the latest release is supported. / Unterstützt wird jeweils nur die neueste Version.
- The programs are not signed yet. Before reporting, check that your download is genuine: compare it with
  `SHA256SUMS` of the release on https://github.com/tmmac-core/corestarter/releases.
  / Die Programme sind noch nicht signiert. Prüfe vor dem Melden deinen Download gegen `SHA256SUMS` des Releases.
